A slider from 0 to 100.

## What it is for
- Volume, opacity and anything else that is a share of the whole.

## How it works
- Percent is where the handle is, from 0 to 100.
- Track Color, Fill Color and Thumb Color follow the theme until you set them.

## Tips
- For a different range, use a Slider, which has a Minimum and a Maximum.
