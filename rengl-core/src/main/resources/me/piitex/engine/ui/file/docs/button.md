A button the player clicks.

## What it is for
- Menus, forms and anything that starts something.

## How it works
- The Text is what it says. It follows the theme's colors for the background, the hover color and the text until you set your own.
- Hover Background is the background while the mouse is over it. Text On Hover is the color of the text then.
- Text Position decides where the text sits in the button when it is bigger than the text.
- On Click is the name of a method that runs when it is clicked. See the Controller on the root for where the method is looked for.

## Tips
- The background can be a gradient, a gradient that moves or a rainbow, and an effect can be drawn behind the text.
- Corner Radius rounds the corners, and Border Color and Border Width draw an outline.
