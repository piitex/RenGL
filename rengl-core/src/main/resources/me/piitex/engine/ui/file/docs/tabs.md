A row of tabs that switches between pages of content.

## What it is for
- Settings screens with a page for each topic, an inventory with a tab for each kind of item.

## How it holds things
- Each element you add to it is one page, and gets a Tab Title to show on its tab. With no title it uses the element's name.
- The tab container sets the size of each page to fill the space under the tabs, so a page's own width and height are not used.
- A new one starts with two empty pages, which you can fill or take away.

## Tips
- Tab Bar chooses which edge the row of tabs is on.
- Put a layout or a container on each page, rather than loose elements, so the page's contents stay together.
