One of the built-in icons.

## What it is for
- Small symbols on buttons, in lists and in toolbars: arrows, a cog, a trash can, a play button.

## Tips
- Icon is the name of the icon. The list in the inspector shows them all.
- Tint is the color it is drawn in. The icons are single-color shapes made to be recolored this way.
- An icon is drawn from a vector picture at the size of the element, so it stays sharp when you make it bigger.
