A switch that is on or off.

## What it is for
- Settings that take effect at once: sound on or off, dark mode, notifications.

## How it works
- On is whether it is switched on. On Toggle is the name of a method that runs when it changes, and is given true or false.
- On Color, Off Color and Knob Color follow the theme until you set them.

## Tips
- The width and height decide the shape. Make the height about half the width for the usual look.
- For a choice that is made with a form and sent later, a Check Box suits better.
