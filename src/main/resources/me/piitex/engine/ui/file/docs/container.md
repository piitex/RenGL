A plain box that holds other elements and puts each one where you place it.

## What it is for
- Grouping elements so they move, fade and hide together.
- Making a panel or a card: give it a background, a border and rounded corners, or turn on Themed Panel to take the look from the theme.
- A free area for placing things by hand. Inside a container every element has an X and a Y, and can be pinned with an anchor so it keeps its place when the container is resized.

## Tips
- A layout (vertical, horizontal, grid...) places its items for you. Use a container when you want to place them yourself.
- Clip Children hides whatever sticks out past the edge. It is on by default.
- Give the container a name to find it from code with `UiFile.find`.
