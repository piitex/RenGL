A box the player types a line of text into.

## What it is for
- Names, searches, chat messages and anything else short.

## How it works
- Placeholder is a grey hint that shows while the box is empty.
- Password shows dots in place of the letters. Read Only lets the text be selected and copied, but not changed.
- Max Length limits how many characters can be typed. -1 means no limit.
- Prefix is text shown before what is typed that can't be edited, such as a currency sign. Align Right is for numbers.
- On Text Change runs every time the text changes, and On Submit when Enter is pressed. Each is the name of a method.

## Tips
- Caret Color and Selection Color follow the theme until you set them.
- For more than one line, use a Text Area. For a number, use a Number Field.
