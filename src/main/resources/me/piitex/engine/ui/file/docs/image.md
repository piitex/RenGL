A picture.

## What it is for
- Logos, icons that are pictures, portraits, backgrounds, anything drawn in an image program.

## How it works
- Image is the file's path in the project, such as `assets/logo.png`. Use the Browse button to pick a file.
- The picture is stretched to the element's width and height.
- If the file can't be found the element shows nothing, and the path is kept so it is not lost.
- PNG, JPEG, WEBP, GIF, BMP and ICO files work. A GIF with more than one frame plays by itself.

## Tips
- Tint paints the picture over with a color, which also lets you make one picture work in several colors. Leave it unset to show the picture as it is.
- For a picture behind other elements, use the Background Effect with Image on a container. It can fill the space in several ways.
