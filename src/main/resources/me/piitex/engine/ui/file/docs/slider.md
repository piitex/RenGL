A handle the player drags along a bar to choose a value.

## What it is for
- Volume, brightness, a quantity in a range: values where the exact number matters less than the feel.

## How it works
- Minimum and Maximum are the values at the two ends. Value is where the handle is. Step makes it move in jumps, and 0 moves it smoothly.
- On Value Change is the name of a method that runs while it moves, and is given the value.
- Track Color, Fill Color and Thumb Color follow the theme until you set them.

## Tips
- For a value from 0 to 100, use a Percent Slider. For an exact number, use a Number Field.
