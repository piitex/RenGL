A layout that puts its items in a table with a set number of columns.

## What it is for
- An inventory, a keypad, a gallery: anything laid out in rows and columns.

## How it works
- Columns is how many there are in a row. Items fill the first row left to right, then the next row, and so on.
- Each column is as wide as its widest item and each row as tall as its tallest.
- Column Spacing and Row Spacing are the gaps between them. Padding is the space round the edge.
- Alignment decides where each item sits in its cell when it is smaller than the cell.

## Tips
- Fit Width and Fit Height to Content make the grid as big as its table.
