A field for a number, with arrows to step it up and down.

## What it is for
- Quantities, sizes, prices, a level: anything where the player should enter a number rather than pick from a list.

## How it works
- Minimum and Maximum are the limits. Step is how much the arrows change it. Decimals is how many digits show after the point.
- The player can type a number as well as use the arrows. A number outside the limits is brought back to the nearest one.
- On Value Change is the name of a method that runs when the number changes.

## Tips
- For a number picked by dragging, use a Slider.
