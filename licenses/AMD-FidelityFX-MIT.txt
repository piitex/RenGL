AMD FidelityFX SDK: license of its source files and headers (the MIT part of its license file)

The rengl-upscale module calls the FidelityFX libraries and follows the interface of the SDK's headers
(Kits/FidelityFX/api/include, upscalers/include, framegeneration/include). It contains none of the SDK's
files. The libraries are not part of RenGL.

The SDK's license file has two parts. The first (binary-only redistribution, no reverse engineering,
notices reproduced) covers all files except those the file lists. The second, the text below, covers the
listed files. In the version we read, that list includes the headers and the compiled libraries in
Kits/FidelityFX/signedbin (amd_fidelityfx_*.dll). If you ship those libraries, take the license file from
the SDK you got them from, since its list can change, and ship it with them.
