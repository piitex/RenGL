RenGL (all modules)

This artifact has no classes of its own. It is the whole engine in one dependency: it depends on every RenGL module except the examples and rengl-upscale.

The API documentation is in the Javadoc of each module (rengl-core, rengl-audio, rengl-3d and so on), and in the guides at github.com/piitex/RenGL/tree/main/docs.
