A container whose contents can be scrolled when they are bigger than it.

## What it is for
- A long list, a settings page or a log that doesn't fit the space it has.
- Scrolling goes up and down, left and right, or both, with the mouse wheel and a bar at the edge.

## Tips
- Put a vertical layout inside and let the layout grow past the bottom: only the part that fits is shown, and the rest scrolls into view.
- Turn off the direction you don't want. A page that only scrolls vertically should have Scroll Horizontally off.
- Scroll Speed is how far one turn of the wheel moves the contents, in points.
