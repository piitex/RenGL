A box that shows a color and opens a picker to change it.

## What it is for
- Letting the player choose a color: a team color, a paint color, a theme.

## How it works
- Color is the color it holds. Allow Transparency adds a slider for how see-through it is.
- On Change is the name of a method that runs when a color is picked, and is given the color.

## Tips
- Text Color and Font Size style the code shown in the box.
