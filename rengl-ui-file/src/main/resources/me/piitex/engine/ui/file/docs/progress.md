A bar that shows how far along something is.

## What it is for
- Loading, health, experience, downloads: any amount from nothing to full.

## How it works
- Progress is a number from 0 (empty) to 1 (full). Change it from code while the game runs.
- Indeterminate shows a bar that keeps moving, for something that is taking an unknown time.
- Fill Color is the color of the part that is filled. It follows the theme until you set it.

## Tips
- Give the bar a Corner Radius half its height for rounded ends.
- The bar only shows a value. To let the player change one, use a Slider.
