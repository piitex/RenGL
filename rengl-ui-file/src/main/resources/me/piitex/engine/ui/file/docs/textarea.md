A box the player types many lines of text into.

## What it is for
- Notes, descriptions, chat input, a log that can be copied from.

## How it works
- Wrap Lines starts a new line at the edge of the box. Turn it off to scroll sideways instead.
- Read Only lets the text be selected and copied but not changed.
- Placeholder is a grey hint that shows while it is empty.
- On Text Change runs every time the text changes, and On Submit when Ctrl or Cmd and Enter are pressed. Each is the name of a method.

## Tips
- Show Scrollbar draws the bar at the edge when the text is longer than the box.
- For one line, use a Text Field.
