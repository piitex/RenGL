A layout that puts its items in a single row, left to right.

## What it is for
- Toolbars, button rows and a label next to its field.

## How it works
- You don't place the items. The layout sets each one's position and keeps doing it.
- The items keep their own sizes. Spacing is the gap between them and Padding is the space kept clear round the edge.
- Alignment decides where the row sits in the layout, and for items shorter than the layout, how they line up up and down.

## Tips
- Turn on Fit Width to Content and the layout grows and shrinks with its items.
- A row that gets too long does not wrap. Use a Flow Layout for items that should wrap onto a new line.
