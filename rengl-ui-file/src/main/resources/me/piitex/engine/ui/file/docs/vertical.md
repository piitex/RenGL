A layout that puts its items in a single column, top to bottom.

## What it is for
- Menus, forms and lists: anything that reads down the page.

## How it works
- You don't place the items. The layout sets each one's position and keeps doing it, so adding, taking away or resizing an item moves the rest.
- The items keep their own sizes. The layout only decides where they go.
- Spacing is the gap between items, and Padding is the space kept clear round the edge.
- Alignment decides where the column sits in the layout, and for items narrower than the layout, which side they line up to.

## Tips
- Turn on Fit Height to Content and the layout grows and shrinks with its items.
- Anchor and X and Y are ignored for an item inside a layout. Anchor the layout itself instead.
- Put a horizontal layout inside to make a row in the column, such as a label next to a field.
