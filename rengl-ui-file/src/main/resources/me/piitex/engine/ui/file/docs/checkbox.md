A box that is ticked or not ticked.

## What it is for
- Options that are on or off: "Remember me", "Show hints", the items in a list that the player picks any number of.

## How it works
- Checked is whether it is ticked. On Toggle is the name of a method that runs when it changes, and is given true or false.
- Check Color is the color of the tick. It follows the theme until you set it.

## Tips
- Put a Text element beside it in a horizontal layout for the label.
- For one choice out of several, use Radio Buttons. For a switch that looks like a switch, use a Toggle Switch.
