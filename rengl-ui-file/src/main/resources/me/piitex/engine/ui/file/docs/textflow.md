Text that wraps onto more lines when it is wider than the element.

## What it is for
- Paragraphs: descriptions, dialogue, help text, a story.

## How it works
- The text is broken into lines to fit the width. Make the element wider or narrower to change where the lines break.
- Height Fits Text makes the element as tall as the wrapped text. Turn it off to give it a set height, and any text that doesn't fit is cut off, or scrolls if it can.
- Max Lines cuts the text after that many lines and puts an ellipsis on the last.
- A new line in the text is kept.

## Tips
- Align is whether the lines sit left, middle or right. Line Spacing adds space between lines.
- Padding is the space between the element's edge and its text, which is useful with a background.
