A line of text.

## What it is for
- Titles, labels, scores, captions: anything short that doesn't need to wrap.

## Tips
- The element works out its own size from its text and font size, so it has no width or height to set.
- Text Color can be a plain color, a gradient, a gradient that moves, or a rainbow that cycles on its own.
- For text that wraps onto more lines, use Wrapped Text. For something the player types into, use a Text Field.
- Bold and Italic change the weight and slant of the whole text. They can't be mixed within one line.
